# Kemuel Godoy - Landing Page

Landing Page institucional e de conversão para **Kemuel Godoy** (Especialista e Consultor de Consórcios Ademicon).

## 🌐 Publicação no GitHub Pages

Este projeto está configurado para publicação através do GitHub Pages:
- **URL|**: [https://leandevlima.github.io/Kemuel_Godoy/](https://leandevlima.github.io/Kemuel_Godoy/)

### Como funciona o deploy:
1. **GitHub Actions (Automático)**:
- Configurado via `.github/workflows/deploy.yml`.
- No GitHub, acesse **Settings** > **Pages** e selecione **Source: GitHub Actions**.

2. **Deploy direto da branch (`main` / root)**:
- Alternativamente, pode selecionar **Source: Deploy from a branch**, branch `main`, diretório `/ (root)`. O arquivo `index.html` e o `.nojekyll` já estão posicionados na raíz.
